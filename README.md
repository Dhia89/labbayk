# Labbayk – Omra et Hajj

Le compagnon du pèlerin : la Omra et le Hajj étape par étape, les dou'as, la Qibla, le retour à l'hôtel et un bouton d'urgence. L'app fonctionne **sans internet**.

## Télécharger l'app Android

👉 **[Télécharger labbayk.apk](https://github.com/Dhia89/labbayk/releases/latest/download/labbayk.apk)**

À l'installation, Android affiche « source inconnue » : appuyez sur **Paramètres**, autorisez l'installation, puis revenez en arrière et appuyez sur **Installer**.
